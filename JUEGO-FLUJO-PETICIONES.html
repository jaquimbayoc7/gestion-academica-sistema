Conceptos reforzados

🔀
Flujo de Ida

Cliente → ValidationPipe → Controller → Service → Repository → Prisma → PostgreSQL

🔁
Flujo de Vuelta

PostgreSQL → Prisma mapea objetos → Repository → Service (lógica) → Controller → JSON Response

📝
CRUD ↔ SQL

POST→INSERT, GET→SELECT, PUT→UPDATE, DELETE→DELETE. Include→LEFT JOIN.

🧮
Lógica en Service

Verificar existencia, calcular notaDefinitiva, capturar errores Prisma (P2002, P2003).

⚠️
Errores ida y vuelta

BD rechaza → Prisma lanza error → Service captura → Exception HTTP → Response con status code.

🔗
Dependencias FK

Orden de inserción: padres primero, hijos después. No puedes borrar padres con hijos.
